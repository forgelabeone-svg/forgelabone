# 🤝 Contributing

ForgeLab is **closed-source** software. The engine and application code are not publicly available.

This repository exists to provide public documentation, a changelog, and a place for community feedback.

## How You Can Help

### 🐛 Bug Reports
Found something broken on [forgelab.one](https://forgelab.one)? Open an issue with:
- What you expected to happen
- What actually happened
- Steps to reproduce (browser, OS, project type)

### 💡 Feature Requests
Have an idea? Open an issue with the `enhancement` label. Popular requests are considered for the [roadmap](ROADMAP.md).

### 📖 Documentation Fixes
Typos, outdated info, or unclear explanations in these docs? Pull requests for documentation are welcome.

## What We Don't Accept

- PRs for the ForgeLab engine (source code is not in this repo)
- Requests to open-source the platform
