# 🔒 Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ForgeLab, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, send a description to: **security@forgelab.one**

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge your report within 48 hours and aim to resolve confirmed issues promptly.

## Scope

This policy applies to the ForgeLab platform at **forgelab.one**.

Out of scope: third-party services (OpenRouter, Cloudflare, Supabase, WebContainer API).
